# 🧩Wozzle

A Wordle-like puzzle game where players guess words within limited attempts.

## About

Wozzle is a word-guessing puzzle game inspired by Wordle. Players try to guess a hidden word by submitting guesses and receiving feedback on letter accuracy and positioning.

## How to Play

1. **Guess the word**: Enter a valid word of the correct length
2. **Check feedback**: After each guess, you'll receive clues:
    - ✅ **Green**: Letter is correct and in the right position
    - 🟨 **Yellow**: Letter is in the word but wrong position
    - ⬜ **Gray**: Letter is not in the word
3. **Use clues**: Apply the feedback to make better guesses
4. **Win**: Guess the word within the allowed attempts (typically 6 tries)

## How to Run

```bash
# Clone the repository
git clone https://github.com/Oraange/Wozzle.git
cd puzzles/wordle

# There are no dependency!
python3 main.py
```
